=== python ping_scan.py --help ===
usage: ping_scan.py [-h] [--version] --subnet SUBNET [--timeout TIMEOUT]
                    [--concurrency CONCURRENCY] [--output] [--output-file OUTPUT_FILE]
                    [--no-color] [--no-emoji] [--quiet] [--json]

MOURA-TOOLS Ping Scanner — ICMP ping sweep with stylish terminal output.

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --subnet SUBNET       Target subnet in CIDR notation (e.g. 192.168.1.0/24)
  --timeout TIMEOUT     Per-host timeout in seconds (default: 1.0). On Unix, fractional values are
                        rounded up to the nearest integer for ping -W.
  --concurrency CONCURRENCY
                        Number of parallel ping workers (default: 8)
  --output              Save online hosts to a file
  --output-file OUTPUT_FILE
                        Output file path (default: results.txt)
  --no-color            Disable ANSI color output
  --no-emoji            Disable emoji characters (for terminals with limited Unicode support)
  --quiet               Print only online IPs, one per line — no banner/progress/styling (good for
                        pipes)
  --json                Output results as JSON. Mutually exclusive with --quiet.
